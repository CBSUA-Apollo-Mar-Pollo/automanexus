# AGENTS

This repository uses .agent.md as the canonical project-specific instruction file for AI coding assistants.

Before making any code changes, review, refactor, debugging, or architectural decisions, read and follow .agent.md first.

Rules:

- Do not override its guidance with generic default instructions.
- If a task appears to conflict with .agent.md, follow the repository-specific guidance in .agent.md.
- Keep changes minimal, simple, and aligned with the project’s engineering standards.
